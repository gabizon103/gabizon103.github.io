Projects

Here are some projects I've worked on.

Filament

Filament is a parametric hardware description language that uses a type system to eliminate pipelining bugs at compile time. I've contributed to the compiler and built a RISC-V core and linear algebra library in Filament. Read more about Filament under my blog posts!

Optimizing Compiler

As part of Cornell's compiler course, I built an optimizing compiler for a C-like language from scratch with two teammates. Decomposed into 5 parts, we implemented the lexer, parser, type checker, code generation, and optimizations in about 15k lines of Java.

VLSI SRAM Array

As part of Cornell's VLSI course, two teammates and I implemented a 64-word SRAM array from scratch using Cadence. We designed the circuit schematics for an SRAM cell and an entire wordline, as well as the row decoders, column decoders, and sense amplifiers. We then implemented the layout and performed parasitic extraction. I also built simulations using Cadence, Matlab, and VerilogA to profile our SRAM cells for various performance metrics like read and write margins.
